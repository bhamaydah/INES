# الاستراتيجية الوطنية للتربية والتعليم في العراق 2022–2031

موقع بثلاث لغات (عربي · English · کوردی) مع لوحة متابعة وواجهة إدارة داخلية، للنشر على **Cloudflare Pages عبر GitHub**.

## الجديد في هذه النسخة — طبقة الإجراءات التنفيذية (نسخة أولية للفحص)

بُنيت هذه الطبقة استناداً إلى تحليل استمارتَي وزارة التربية ووزارة التعليم العالي، **دون نقل أي بيانات منهما**؛ تصل المنصة فارغة تماماً للفحص.

**1) تبويب جديد «الإجراءات التنفيذية»** بجانب «مؤشرات الأداء» و«البرامج ذات الأولوية»، في لوحة المتابعة العامة وفي واجهة الإدارة.

**2) حقول الإجراء** (مشتقة من الاستمارتين):

| المجموعة | الحقول |
|---|---|
| تعريف الإجراء | العنوان، القطاع، المكون (قائمة من ركائز الاستراتيجية)، الهدف، البرنامج، البرنامج الفرعي، الوزارة، الجهة المنفذة، تاريخا البداية والإنجاز |
| القياس والربط | مؤشر القياس كما في الاستمارة، **ربط الإجراء بمؤشر نتائج من الاستراتيجية**، وحدة القياس من قائمة مقنَّنة، المستهدف الكلي، المتحقق الكلي، موقف الإجراء |
| التمويل | الكلفة، التمويل المخصص، المصروف، **العملة ووحدة المبلغ كحقلين منفصلين**، مصدر التمويل، والفجوة التمويلية محسوبة تلقائياً |
| التحديث الدوري | سجل لكل فترة (مثل 2025-Q1): مستهدف الفترة، المتحقق، ما أُنجز، سبب الانحراف، الخطوة التالية، مع اسم المُدخِل وتاريخه — لا تُمحى بيانات الفصل السابق |
| التحقق والاعتماد | حالة (مسودة / قيد المراجعة / معتمد)، رابط الدليل، ملاحظات |

**3) النشر بعد الاعتماد فقط:** الزائر لا يرى إلا الإجراءات المعتمدة؛ المسودات وقيد المراجعة تظهر للمسجّلين فقط.

**4) فصل القياسين:** لوحة الإجراءات تعرض «متوسط تنفيذ الإجراءات» منفصلاً عن تقدم مؤشرات النتائج، مع تنبيه مكتوب بأن ارتفاع الأول لا يعني تحسّن الثاني. ولا تُحتسب نسبة تقدم للإجراء إلا من مستهدف ومتحقق رقميين.

**5) الاستيراد من Excel بشاشة مطابقة:**
- يقبل `.xlsx` و`.csv`، مع اختيار الورقة ورقم صف العناوين (استمارة التربية عناوينها في الصف 3).
- **مطابقة تلقائية للأعمدة** بأسماء الاستمارتين (القطاع، المكون، الهدف، البرنامج، الاجراء التنفيذي / المشروع، مؤشر القياس، المستهدف الكلي، وحدة القياس، موقف الاجراء، الكلفة، التمويل، المصروف…) مع إمكانية تعديل أي مطابقة يدوياً.
- **تقرير تحقق قبل الاستيراد:** عدد الصفوف، الصالح للاستيراد، ما سيُتجاوز، وتنبيهات (مستهدف غير رقمي، وحدة غير معروفة، عناوين مكررة، صفوف بلا مكون) + معاينة خمسة صفوف.
- كل ما يُستورد يدخل **كمسودة**، ولا تُستورد نسب الإنجاز الجاهزة من الملف.
- تصدير CSV للبيانات الحالية، وتحميل قالب فارغ بالأعمدة المعتمدة.

**6) واجهات API الجديدة:** `GET /api/actions` (المعتمد فقط للعموم) · `PUT /api/actions` · `POST /api/actions/import` · `DELETE /api/actions/:id` (لمدير النظام).

**ملاحظة تقنية:** تُخزَّن الإجراءات في مفتاح KV واحد (`actions`) بدل مفتاح لكل إجراء، حتى يبقى الاستيراد الكبير عملية كتابة واحدة ضمن حد الخطة المجانية (1,000 كتابة يومياً). الحد الأقصى المضبوط 2,500 إجراء.

**الخطوة التالية المقترحة (غير منفَّذة في هذه النسخة):** رفع ملفات الأدلة داخل المنصة عبر Cloudflare R2 (10 غيغابايت مجاناً، تنزيل بلا رسوم)؛ حالياً يُسجَّل الدليل كرابط.

   - شريط **«بدعم من»**: اليونسكو، اليونيسف، البنك الدولي، الاتحاد الأوروبي.
   - شعار صغير في الشريط العلوي بجانب اسم الموقع.
   - الأحجام موحّدة بصرياً (الأختام الدائرية 66px، الشعارات النصية 46–54px) مع توزيع متساوٍ داخل الصف، وتصغير تلقائي على الشاشات الصغيرة.
2. **نظرية التغيير لكل Pillar**: سطر سردي «إذا … فإن …» أعلى شكل نظرية التغيير في كل ركيزة من الركائز الثلاث عشرة، بثلاث لغات، مستمد من الفصل الخامس.
3. **عدّاد التحميل**: يظهر عدد مرات تحميل كل نسخة تحت بطاقتها في صفحة «تحميل» وفي صفحة وثيقة الاستراتيجية، ويُحدَّث لحظياً عند الضغط.
4. **الاستعراض أونلاين**: زر «استعراض أونلاين» يفتح قارئ PDF داخل الموقع (`#/read/ar` و`#/read/en`) مع تبويب لتبديل اللغة وزر فتح في تبويب جديد وزر تحميل. إذا كان المتصفح لا يعرض PDF داخلياً (بعض متصفحات الهاتف) يظهر بديل بزر «فتح في تبويب جديد».

## محتويات المستودع

| المسار | الوظيفة |
|---|---|
| `index.html` | الموقع كاملاً (ثلاث لغات) |
| `assets/logos/` | شعارات الجهات (PNG بخلفية شفافة) — انظر `assets/logos/README.txt` |
| `docs/` | نسختا الاستراتيجية (PDF) للتحميل والاستعراض |
| `functions/api/[[path]].js` | الخادم: تسجيل الدخول، حفظ بيانات المتابعة، إدارة المستخدمين، عدّاد التحميل |
| `data/tracking.json` | بيانات احتياطية تُستخدم فقط إذا لم تكن الواجهة الخلفية مفعّلة |

> `index.html` ومجلدات `functions` و`assets` و`docs` و`data` يجب أن تكون في **جذر المستودع** مباشرة.

## خطوات التفعيل (مرة واحدة)

### 1) رفع الملفات إلى GitHub
استبدل محتوى المستودع بهذه الملفات، ثم Commit و Push.

### 2) إعدادات البناء في Cloudflare Pages
Settings ← Build:
- Framework preset: **None**
- Build command: *(فارغ)*
- Build output directory: `/` (أو فارغ)

### 3) مخزن البيانات KV
- Workers & Pages ← **KV** ← Create namespace ← الاسم: `ines-tracking`
- مشروعك ← Settings ← **Bindings** ← Add ← **KV namespace**: Variable name `INES_KV`

### 4) المتغيرات السرية
Settings ← **Variables and Secrets** (النوع: Secret، بيئة Production):

| الاسم | القيمة |
|---|---|
| `ADMIN_USERNAME` | اسم مستخدم المالك بأحرف لاتينية صغيرة |
| `ADMIN_PASSWORD` | كلمة مرور قوية (12 حرفاً فأكثر) |
| `SESSION_SECRET` | نص عشوائي طويل (40 حرفاً فأكثر) |
| `ADMIN_NAME` | *(اختياري)* الاسم الظاهر في سجل التحديثات |

### 5) إعادة النشر
Deployments ← آخر نشر ← **Retry deployment**.

### 6) الدخول
زر **دخول الإدارة** (أو `موقعك/#/admin`)، ثم أضف حسابات الفريق من تبويب **إدارة المستخدمين**.

## واجهات API المضافة

| الطريقة | المسار | الوصف |
|---|---|---|
| GET | `/api/downloads` | عدد التحميلات لكل نسخة |
| POST | `/api/count/ar` \| `/api/count/en` | تسجيل عملية تحميل واحدة |

عدّاد التحميل مخزَّن في KV بالمفتاحين `dl:ar` و`dl:en`. إذا لم يكن ربط `INES_KV` مفعّلاً، يختفي العدّاد تلقائياً ولا يظهر خطأ للزائر.

## الأمان
- كلمات مرور المستخدمين مشفّرة (PBKDF2-SHA256، 100,000 دورة)، وحساب المالك محفوظ كسرّ في Cloudflare.
- الجلسة في كوكي HttpOnly و Secure و SameSite=Strict لمدة 8 ساعات.
- قفل مؤقت 15 دقيقة بعد 5 محاولات دخول خاطئة من العنوان نفسه.
- القراءة عامة؛ الحفظ وإدارة المستخدمين للحسابات المسجّلة فقط.

## ملاحظات
- كل تحديث يُحفظ باسم المستخدم مع سجل آخر 15 تحديثاً لكل مؤشر أو برنامج.
- الخطة المجانية لـ Cloudflare KV تسمح بـ 1,000 عملية كتابة يومياً (كل تحميل = عملية كتابة واحدة).
- النص الكردي (سوراني) ترجمة أُعدّت خصيصاً للموقع، ويُستحسن مراجعتها من مترجم معتمد قبل الإطلاق الرسمي.
- الشعارات المستخدمة هي الملفات التي زوّدتني بها؛ يُرجى التأكد من موافقة الجهات على استخدامها في الموقع.
