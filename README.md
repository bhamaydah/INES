# الاستراتيجية الوطنية للتربية والتعليم في العراق 2022–2031

موقع بثلاث لغات (عربي · English · کوردی) مع لوحة متابعة وواجهة إدارة داخلية، للنشر على **Cloudflare Pages عبر GitHub**.

## محتويات المستودع

| المسار | الوظيفة |
|---|---|
| `index.html` | الموقع كاملاً |
| `docs/` | نسختا الاستراتيجية (PDF) للتحميل |
| `functions/api/[[path]].js` | خادم الإدارة: تسجيل الدخول، حفظ بيانات المتابعة، إدارة المستخدمين |
| `data/tracking.json` | بيانات احتياطية تُستخدم فقط إذا لم تكن واجهة الإدارة مفعّلة |

> مهم: يجب أن يكون `index.html` ومجلد `functions` في **جذر المستودع** مباشرة، وليس داخل مجلد فرعي.

## خطوات التفعيل (مرة واحدة)

### 1) رفع الملفات إلى GitHub
استبدل محتوى المستودع الحالي بهذه الملفات (بما فيها مجلد `functions`)، ثم Commit و Push.

### 2) إعدادات البناء في Cloudflare Pages
Workers & Pages ← مشروعك ← Settings ← Build:
- Framework preset: **None**
- Build command: *(فارغ)*
- Build output directory: `/` (أو فارغ)

### 3) إنشاء مخزن البيانات KV
- Workers & Pages ← **KV** ← Create namespace ← الاسم: `ines-tracking`
- مشروعك ← Settings ← **Bindings** ← Add ← **KV namespace**
  - Variable name: `INES_KV`
  - KV namespace: `ines-tracking`

### 4) إضافة المتغيرات السرية
مشروعك ← Settings ← **Variables and Secrets** ← Add (النوع: **Secret**)، لبيئة Production:

| الاسم | القيمة |
|---|---|
| `ADMIN_USERNAME` | اسم مستخدم المالك بأحرف لاتينية صغيرة، مثل `bilal` |
| `ADMIN_PASSWORD` | كلمة مرور قوية (12 حرفاً فأكثر) |
| `SESSION_SECRET` | نص عشوائي طويل (40 حرفاً فأكثر) |
| `ADMIN_NAME` | *(اختياري)* الاسم الظاهر في سجل التحديثات |

### 5) إعادة النشر
Deployments ← آخر نشر ← **Retry deployment**. الإعدادات الجديدة تُطبَّق على النشر الجديد فقط.

### 6) الدخول
افتح زر **دخول الإدارة** (أو `موقعك/#/admin`) وسجّل الدخول بحساب المالك. من تبويب **إدارة المستخدمين** أضف حسابات فريق المتابعة بدور محرر أو مدير نظام.

## الأمان
- كلمات مرور المستخدمين مشفّرة (PBKDF2-SHA256)، وحساب المالك محفوظ كسرّ في Cloudflare لا يظهر في الكود.
- الجلسة في كوكي HttpOnly و Secure و SameSite=Strict لمدة 8 ساعات.
- قفل مؤقت 15 دقيقة بعد 5 محاولات دخول خاطئة من العنوان نفسه.
- القراءة عامة؛ الحفظ وإدارة المستخدمين للحسابات المسجّلة فقط.

## ملاحظات
- كل تحديث يُحفظ باسم المستخدم، مع سجل آخر 15 تحديثاً لكل مؤشر أو برنامج.
- الخطة المجانية لـ Cloudflare KV تسمح بـ 1,000 عملية كتابة يومياً، وهي كافية لفريق متابعة.
- إذا لم تُضبط الخطوات 3–5 يعمل الموقع طبيعياً، وتعرض صفحة الإدارة رسالة بأنها غير مفعّلة.
- النص الكردي ترجمة أُعدّت للموقع ويُستحسن مراجعتها من مترجم معتمد.
